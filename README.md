# who_am_i

A self-guided framework for discovering your **values**, **moral framework**, and **talents**, with room to grow into other topics.

| File | What it is |
|---|---|
| [`whoami_general.md`](whoami_general.md) | The framework: exercises and prompts. Same for everyone. |
| [`whoami_personal.md`](whoami_personal.md) | An empty template for **your** answers. |

## Getting started (keep your answers private)

Your answers in `whoami_personal.md` are personal. **Don't fork this repo to fill it in.** GitHub forks of a public repo are always public, and they can't be made private.

Make a private copy instead:

1. Click **Use this template → Create a new repository** at the top of this page.
2. Name it, and set visibility to **Private**.
3. Clone your new private repo and work through `whoami_general.md`, writing your answers in `whoami_personal.md`. You can do it alone, with a partner, or with an AI assistant as a conversation partner (see *Get a mirror* in the framework).

No GitHub account, or don't want one? Download the two files and keep them anywhere private. A notes app or a local folder works fine.

## Improving the framework

Suggestions and new modules are welcome. To contribute, make a **separate public fork** used only for framework changes, edit `whoami_general.md` (and the matching empty sections in `whoami_personal.md`), and open a pull request.

**Never commit your personal answers to a public fork or include them in a pull request.**
